**题面：**

### 线代660 561题（★ 基础 · 反对称矩阵、伴随矩阵）

**题面：**
设 A、B 均为 n 阶反对称矩阵，且 AB = BA，则下列结论不正确的是：
(A) A+B 是反对称矩阵　(B) AB 是对称矩阵
(C) A* + B* 是反对称矩阵　(D) 2A + 3B 是反对称矩阵
（答案：C）

**我的作答：** 首次作答误选（以为 A* 必为反对称）；经解析后确认为 C ✅

**判定：** ✅（首次做错，已订正）

**卡点&复盘：**
- 反对称矩阵理解不透彻：首次未意识到 A* 是否为反对称取决于 n 的奇偶。
- 关键结论：n 为偶数且 A 可逆时 A* 反对称；n 为奇数时 |A|=0 且 A* 实际为对称矩阵（或零矩阵）。故 C 不恒成立。
- (A)(B)(D) 直接由转置性质可证成立。
- 标记：🔴 薄弱点，需回头巩固"反对称矩阵与伴随矩阵"的关系。

**考点：** 反对称矩阵、伴随矩阵

### 线代660 563题（★★ 基础应用 · 初等变换与初等矩阵）

**题面：**
已知 A 是三阶矩阵，将 A 的 1、2 两行互换得 B，再将 B 第 3 列的 -2 倍加到第 1 列得单位阵，则 A = ?
（选项 A 为 [[0,1,0],[1,0,0],[2,0,1]]）

**我的作答：** A（逆推正确）✅

**判定：** ✅

**卡点&复盘：**
- 行互换：B = E12 A（左乘）；列变换：I = B E31(-2)（右乘）。
- 逆推：A = E12^{-1} I E31(-2)^{-1} = E12 E31(2)。
- 从 I 先 C1+2C3、再 r1↔r2，得 A = [[0,1,0],[1,0,0],[2,0,1]]。
- 基础档，无卡点。

**考点：** 初等变换与初等矩阵
